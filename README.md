# smart-agriculture-harmony
# 智能赣农 - 基于鸿蒙的智慧农业物联网系统
项目简介
本项目为校企实训落地的智慧农业一体化系统，基于 OpenHarmony 鸿蒙系统、小熊派 BearPi-HM_Nano 硬件、Python Flask 轻量后端与 MaxKB 大模型，构建「感知采集-云端传输-移动端管控-AI 智能分析」完整业务闭环。
实现农田环境数据采集、设备远程管控、农事智能问答、环境异常预警四大核心功能，覆盖硬件、通信、后端、前端、AI 全链路开发与联调。
##技术栈
| 感知层（南向硬件） | BearPi-HM_Nano（Hi3861 SoC）/ OpenHarmony / MQTT 协议 / 温湿度/土壤/光照多传感器 |
| 服务层（后端） | Python / Flask / SQLAlchemy / MySQL / paho-mqtt |
| 应用层（北向+AI） | ArkTS / DevEco Studio / MaxKB 大模型 / RAG 知识库 |
核心功能
1. 农田环境实时监测
   硬件终端实时采集温湿度、土壤湿度、光照强度等环境数据，通过 MQTT 上传云端，前端实现数据可视化展示与历史查询。
2. 设备远程智能管控
   支持鸿蒙端手动控制灌溉、通风、遮阳设备启停；同时支持 AI 根据环境阈值自动触发设备联动，实现自适应调控。
3. 农事智能问答交互
   基于农业专属知识库，支持文字/语音双模式农事咨询，大模型输出贴合场景的专业解答，适配田间运维人员使用场景。
4. 环境异常智能预警
   当环境数据超出预设阈值时，系统自动生成预警信息，同步推送至前端，并联动对应设备完成调节，形成智能闭环。
##项目亮点与问题解决
1. MQTT 全链路通信联调
   统一主题命名规范与上下行报文格式，通过「硬件串口→MQTT 服务器→后端日志」分层排查法，解决主题不匹配、数据丢包、字段不一致等通信问题，实现端到端稳定传输，时延控制在百毫秒级。
2. 标准化接口与数据一致性
   基于 Flask 搭建 RESTful 接口，统一入参校验、异常捕获与返回格式；解决前后端字段不统一、中文乱码、数据序列化异常等问题，接口联调通过率 100%。
3. AI 大模型与业务系统联动
   打通 MaxKB 大模型与业务数据链路，实现环境数据同步、知识库问答、阈值预警与设备控制的智能联动，验证了 AI 赋能物联网场景的落地逻辑。
4. 模块化分层架构
   采用三层分布式架构，各模块解耦开发，支持功能迭代与扩展；代码结构清晰，注释完整，具备良好的可维护性。

## 运行与部署
### 环境要求
- 硬件：BearPi-HM_Nano 开发板 + 智慧农业拓展板
- 后端：Python 3.7+、MySQL 5.7+、MQTT 服务器
- 前端：DevEco Studio、OpenHarmony SDK
### 部署步骤
1. **数据库初始化**：导入数据库脚本，创建用户、环境数据、设备状态三张核心表。
2. **启动后端服务**：安装 Python 依赖，配置数据库与 MQTT 连接信息，启动 Flask 服务。
3. **硬件烧录**：将南向采集与控制代码烧录至 BearPi 开发板，配置 WiFi 与 MQTT 服务器地址。
4. **运行鸿蒙应用**：DevEco Studio 打开北向项目，连接设备运行，即可体验完整功能。
